# Product Purchase Table

A simple and clean product purchase table created using **HTML and CSS**. This project demonstrates how to structure tabular data, apply CSS styling, and display product quantities, prices, individual amounts, and a grand total.

## Features

* Displays product serial numbers and names.
* Shows product quantities and per-unit prices.
* Lists the amount for each product.
* Displays the grand total of ₹2,650.
* Blue table headers with white text.
* Interactive row hover effect.
* Centered table layout using CSS Flexbox.
* Simple design with visible table borders.

## Technologies Used

* **HTML5** — Structure and content.
* **CSS3** — Styling, alignment, borders, and hover effects.

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.

No additional software, libraries, or server is required.

## Learning Outcomes

* Understanding HTML table elements such as `table`, `tr`, `th`, and `td`.
* Styling tables using CSS.
* Using CSS Flexbox for alignment.
* Applying hover effects to table rows.
* Organizing structured product and price information.
